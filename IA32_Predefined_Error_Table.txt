IA-32 PREDEFINED ERROR CATALOGUE
Version: 1.0
Format: pipe-separated records
This file is read by the assembler. It is not an assembly source file.

IMPORTANT:
- Keep the [ERROR_DEFINITIONS] and [END_ERROR_DEFINITIONS] markers.
- Each record must contain exactly five fields:
  CODE|CATEGORY|NAME|DESCRIPTION|STAGE
- Do not use the pipe character (|) inside a field.
- The assembler should ignore blank lines and lines beginning with #.

ERROR HANDLING NOTES
1. A forward reference is not an error when first encountered. Add it to the
   symbol table as U and add an appropriate TIT record. Report E401/E103 only
   if it remains unresolved after final resolution.
2. An EXTERN symbol is not automatically an error. A use requiring a linker
   relocation is unsupported by raw flat-binary output and should be reported.
3. An unknown mnemonic means it is absent from this assembler's loaded opcode
   definitions; it does not necessarily mean the CPU architecture lacks it.
4. Report the root cause and avoid cascading duplicate diagnostics.
5. Each occurrence should record error code, source line number, source text,
   and a useful detail.
6. This catalogue is extensible. Add a record using the same five-field format.
7. The catalogue is a practical subset. Add checks as instruction and directive
   support grows.
